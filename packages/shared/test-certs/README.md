# Certificados de prueba (T021)

Solo para pruebas automáticas: CA de prueba, CA intrusa y certificados de servidor con la identidad
`7f3c2a10-1b2c-4d5e-8f90-abcdef123456.impocaribe` (servidor e intruso) u otra identidad. Validez de 100 años.
Nunca se usan fuera de las pruebas; las claves privadas no protegen nada real.
